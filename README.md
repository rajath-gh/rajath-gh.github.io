# Task 5: Deploy a Static Website Using GitHub Pages

A simple static portfolio website (HTML, CSS, JS) hosted for free on GitHub Pages.

**Live site:** https://USERNAME.github.io

## Files
- `index.html` - page structure
- `style.css` - styling (responsive)
- `script.js` - sets the footer year

## Steps
1. Created a public repo named `USERNAME.github.io`
2. Cloned it locally with Git
3. Added the website files
4. Committed and pushed to the `main` branch
5. Enabled GitHub Pages (Settings > Pages > main > root)
6. Opened the live URL to verify
7. Pushed a small update to confirm redeployment

## Concepts learned
Git, GitHub, GitHub Pages, version control, static hosting.
